## Featured Projects

### WhatsApp AI Notification Router
> **Java 21 · Google Gemini · Multimodal AI**

An intelligent notification routing engine that evaluates WhatsApp messages to determine if they should notify the user immediately, get batched into a digest, or be silently muted.

**Key Architecture Highlights:**
- **Context-Aware Routing:** Processes message text, images, and voice notes.
- **Evidence-Based Logic:** Evaluates group metadata, sender history, and notification fatigue scores.
- **Multimodal Pipeline:** Dataset Loader ➔ Context Builder ➔ Gemini Prompt Engine ➔ Dynamic Route Execution.
